# GymTracker 🏋️‍♂️ (v2.0)

GymTracker es una aplicación de seguimiento de entrenamientos moderna, diseñada con una estética analítica profunda (Dark Mode Fintech/Crypto) para poner el foco puramente en tu progreso. Está construida sobre **React** (Frontend), **FastAPI** (Backend) y **PostgreSQL** (Base de datos en Neon).

## 🚀 Acceso a la Aplicación

Puedes acceder a la plataforma web en cualquier momento a través del siguiente enlace:
👉 **[gym-tracker-app-murex.vercel.app](https://gym-tracker-app-murex.vercel.app/)**

## 📱 Cómo Instalarla en tu Celular (PWA)

GymTracker está diseñada como una **Aplicación Web Progresiva (PWA)**, lo que significa que puedes instalarla directamente en tu teléfono sin pasar por una App Store. Operará a pantalla completa como una app nativa.

**Si tienes iPhone (iOS):**
1. Abre el enlace exclusivamente en **Safari**.
2. Toca el ícono de **Compartir** (el cuadro con una flecha hacia arriba en la parte inferior).
3. Desliza hacia abajo y selecciona **"Agregar a inicio"** (Add to Home Screen).
4. Confirma tocando **Agregar**.

**Si tienes Android:**
1. Abre el enlace en **Google Chrome**.
2. Es posible que aparezca automáticamente un cartel en la parte inferior sugiriendo **"Instalar aplicación"**. Si es así, tócalo.
3. Si no aparece, toca el **menú de tres puntos** (arriba a la derecha).
4. Selecciona **"Instalar aplicación"** o **"Añadir a la pantalla de inicio"**.

## 🤖 El Bot de Telegram (El compañero de gimnasio)

Además de la App Web, GymTracker incluye una integración profunda con un Bot de Telegram.
La App Web es ideal para planificar tus rutinas (domingos por la tarde), y el Bot de Telegram es perfecto para registrar tus series mientras entrenas de forma rápida, con una sola mano y sin preocuparte por la mala conexión a internet de los gimnasios.

**¿Cómo funciona?**
1. Regístrate en la App Web.
2. Genera tu código de vinculación de 6 dígitos.
3. Ve a tu bot de Telegram y escribe `/vincular TU_CODIGO`.
4. ¡Listo! Puedes enviar tus rutinas desde la web a Telegram usando el botón "✈️ Enviar a Telegram" y luego simplemente escribir tus series enviando `<peso> <reps>` (Ejemplo: `60 10`).

## 🛠️ Tecnologías Utilizadas

*   **Frontend:** React, Vite, React Router, UI Responsiva (CSS puro inspirado en aplicaciones de criptomonedas).
*   **Backend:** FastAPI (Python), SQLAlchemy, JWT Authentication.
*   **Base de Datos:** PostgreSQL alojada en Neon.
*   **Despliegue:** Vercel (Frontend) y Render (Backend).
